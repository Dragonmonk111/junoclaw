The chain

A lean L1 with certificates that are already post-quantum

Not a Cosmos SDK fork. Not a Tendermint derivative. A small, auditable Rust codebase on Commonware's consensus, broadcast, and storage primitives.

Instant, state-certifying finality

Every block carries a threshold BLS certificate binding the executed state root — ~1 second, no reorgs, no probabilistic settlement.

Hybrid consensus, live today

Every vote is a BLS partial and a MAYO2 signature; every cert needs quorum on both. max(classical, PQ) — a running config, not a roadmap.

Chain-linked certificates

Each cert binds the previous one — light clients verify the certificate chain, not header chains. A succinct proof path built for machines.

Deterministic state machine

KV + Wasm execution, fail-stop divergence detection, certified state-sync, height backfill, tx indexing, gRPC. Small enough to audit.
